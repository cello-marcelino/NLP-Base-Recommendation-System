# Definition of Done Check

Sebelum bilang task selesai, pastikan semua ini terpenuhi:

- [ ] Requirement terpenuhi
- [ ] Code mengikuti architecture rules
- [ ] Naming jelas
- [ ] Tidak ada unnecessary duplication
- [ ] Error handling tersedia
- [ ] Validation tersedia
- [ ] Test relevan tersedia dan lolos
- [ ] Security impact sudah diperiksa
- [ ] Database migration tersedia kalau diperlukan
- [ ] Dokumentasi diperbarui kalau diperlukan
- [ ] Logging tersedia kalau diperlukan

Kalau ada item yang belum terpenuhi, sebutkan ke user sebelum menutup task, jangan diam-diam dilewati.
