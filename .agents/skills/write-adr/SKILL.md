# Write ADR (Architecture Decision Record)

## Langkah
1. Tentukan nomor ADR berikutnya (ADR-001, ADR-002, dst)
2. Tulis Decision: keputusan apa yang diambil
3. Tulis Reason: kenapa keputusan ini yang dipilih
4. Tulis Rejected: opsi lain yang dipertimbangkan tapi tidak dipilih
5. Tulis Reason ditolak: kenapa opsi lain itu tidak dipilih
6. Simpan di folder dokumentasi ADR proyek

Lihat format lengkap di `rules/architecture.md`.
